# Réponse Exercice 15 - Votre première clé de signature

### 1. Commande employée pour la génération
Pour fabriquer la clé de signature de manière sécurisée avec l'algorithme RSA, la commande standard suivante a été exécutée :

```bash
jenga keygen --alias Salle-key --output monapp.keystore
```

### 2. Emplacement de stockage du mot de passe
L'option `--output` permet de choisir le fichier dans lequel la clé est enregistrée.

### Emplacement de la clé

La clé de signature est enregistrée dans le fichier :

```text
monapp.keystore
```
